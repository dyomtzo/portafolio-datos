### 2. Dashboard de Performance Comercial
## Dashboard de Análisis Comercial — E-COMMERCE

Dashboard interactivo desarrollado en Power BI como entrega del Módulo 5 
del Diplomado en Business Intelligence con Power BI (EAFIT).

### Estructura del informe (6 páginas)
- **Inicio** — Panel de navegación principal
- **Ventas** — KPIs de ventas, seguimiento con gauge de cumplimiento y 
  gráfico de columnas por período
- **Productos** — Análisis de embudo de ventas, treemap de categorías 
  y tabla detallada con filtros dinámicos
- **Clientes** — Segmentación geográfica (mapa), árbol de descomposición 
  para análisis causa-raíz y ranking de clientes
- **Indicadores de Presupuesto** — Seguimiento de cumplimiento presupuestal 
  con tabla dinámica y medidor de desempeño
- **Metodología** — Documentación del enfoque analítico utilizado

### Herramientas y técnicas
- Power BI Desktop — modelado de datos y DAX
- Visualizaciones: gauge, treemap, funnel, decomposition tree, mapa geográfico, 
  tablas dinámicas y gráficos de columnas/barras
- Navegación interactiva entre páginas con botones de acción
- Segmentadores (slicers) para filtrado dinámico del usuario
